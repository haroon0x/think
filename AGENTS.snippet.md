# Thinking record

Design records for this repo live in `docs/thinking/`.

- When asked to design something new and no record with `Status: contract` covers it, name that gap in one line before proposing a design.
- Before implementing, read the newest record with `Status: contract`. Implement to its `Proof`. Obey its `Invariant` and `Fence`.
- When code must depart from a record, append a row to its `Divergence log` before writing the departing code, and ask the human to accept it.
